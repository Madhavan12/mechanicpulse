# @mechanicpulse/web

Next.js app: mechanic app + customer report page. See the repo root `CLAUDE.md` and `docs/` for product/architecture context.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — dev server
- `npm run build` — production build (also type-checks)
- `npm run typecheck` — type-check only, no build output
- `npm run lint` — ESLint
